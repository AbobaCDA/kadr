<h1 align="center">Kadr</h1>

<p align="center">
  <b>Локальный поиск по картинкам, видео и файлам — плюс одна клавиша, которая складывает найденное в папку.</b>
</p>

Kadr — это персональный форк [Kensaku](https://github.com/yjid/kensaku) (MIT, © Yash Jangid).
Форк живёт сам по себе: собирается из этого репозитория, ничего не тянет из апстрима и
работает полностью офлайн.

## Запустить

**Самый простой путь: собрать в облаке, ничего не устанавливая.**

```powershell
cd C:\путь\до\kadr
powershell -ExecutionPolicy Bypass -File tools\publish.ps1
```

Скрипт создаст репозиторий на GitHub и запушит код; дальше Actions → «Windows installer» →
Run workflow → через ~20 минут в артефактах лежит готовый установщик. Любой `git push`
пересобирает exe, тег `v*` публикует Release с файлом.

**Локальная сборка.** В архиве — исходники. Собрать один раз (10–20 минут), дальше это обычное приложение:

```powershell
# PowerShell от администратора, из папки с исходниками:
powershell -ExecutionPolicy Bypass -File tools\setup-windows.ps1
```

Скрипт поставит недостающее (Rust, Build Tools C++, Node) и соберёт установщик.
Вручную — три команды: `npm ci` → `npm run dist` → готовый
`src-tauri\target\release\bundle\nsis\kadr_1.0.16_x64-setup.exe`.
Подробно, включая портативный режим и разбор ошибок: [docs/QUICKSTART.ru.md](docs/QUICKSTART.ru.md).

## Что добавлено поверх Kensaku

### 1. Поиск реально показывает всё

В апстриме выдача упиралась в потолок: ranked-запрос собирал `limit × 3` кандидатов
(150 строк при дефолте) и сообщал это число как «всего найдено», а листинги на каждую
страницу заново пересчитывали весь набор. Отсюда «104 000 картинок найдено» и три
страницы в сетке.

- Листинги (`type:image`, `in:~/Pictures`, `ext:png size:>1mb`) — это keyset-пагинация по
  путям поверх кэша порядка: `O(log n + limit)` на страницу, ~11 мс на 100 строк при
  100 000 картинок в индексе, точный счётчик.
- Ranked-запросы углубляют пул кандидатов пропорционально запрошенной странице — листать
  можно до последнего совпадения.
- Ответ отдаёт `has_more` / `next_after` / `total_exact`; сетка останавливается по
  `has_more`, а не по сравнению с приблизительным счётчиком (для ranked он показывается
  как `N+`).
- Дедупликация страниц идёт по `ref` с набором уже загруженных путей — страницы больше
  не «съезжают» и не пропускают строки.

### 2. Скил «в коллекцию» — одна клавиша

Нашёл картинку или видео → `Ctrl+D` → файл уезжает в папку коллекции.

- **Папка спрашивается один раз.** Первое нажатие открывает выбор папки; ответ
  сохраняется в конфиг, дальше всё молча.
- **Перемещение по умолчанию** (в настройках переключается на копирование).
- **Ничего не перезаписывается:** при совпадении имени получается `файл (2).png`.
- Переезд между дисками (C: → D:) обрабатывается правильно: копия, проверка, удаление
  оригинала — источник исчезает только после успешной записи.
- Работает только по картинкам и видео: `pdf`, `docx`, папки и архивы скил не трогает.
- Строка исчезает из выдачи только после подтверждения от бэкенда, и сразу же
  вычищается из метаданных — поиск не отдаёт путь, которого больше нет.
- Тост внизу: «Перемещено в …» с кнопками **Открыть папку** и **Изменить папку**.
- Тот же скил есть в контекстном меню (правый клик по результату).
- Сочетание, папка и режим — в **Настройки → Общие → Коллекция**.

Хоткей намеренно **внутриоконный**: глобальная клавиша, которая молча уносит файлы из
папки, где ты сейчас работаешь, — плохая идея. Если понадобится глобальный — это одна
строка, `tauri-plugin-global-shortcut` уже подключён.

## Сборка

Подробно — в [docs/BUILD.md](docs/BUILD.md). Коротко, на Windows:

```powershell
npm ci            # или bun install
npm run dist      # → src-tauri\target\release\bundle\nsis\kadr_1.0.16_x64-setup.exe
npm run dist:dir  # только kadr.exe, без установщика
```

Как сделать exe компактнее (до −45 МБ без потери поиска по именам и содержимому):
[docs/BUILD.md → How compact can the exe be](docs/BUILD.md#how-compact-can-the-exe-be).

Переименовать форк под себя — `tools/rebrand.sh "Имя" "reverse.dns.id" "exe-name"`.

## Что внутри

| Слой | Реализация |
|---|---|
| Оболочка | Tauri 2 (Rust) + React 19 + Vite |
| Метаданные | SQLite (пути, размер, mtime, dev/ino, burst) + арена в памяти |
| Fuzzy по именам | `nucleo-matcher` |
| Полнотекст | Tantivy (BM25) + regex |
| Семантика | статическая таблица эмбеддингов, локально |
| Извлечение | PDF, Office, OCR (Tesseract / опционально PP-OCR) |
| Агенты | MCP + локальный HTTP + CLI, только чтение |

## Приватность

Индекс, конфиг, метаданные, миниатюры — в локальной папке данных
(`%APPDATA%\kensaku`, `~/.config/kensaku`). Сеть нужна только для проверки обновлений
(отключается в настройках) и для скачивания опциональных OCR/модельных пакетов.

Имя папки данных специально оставлено от апстрима: так существующая установка сохраняет
индекс после переименования и не пересобирает 100 000 файлов заново.
